# Documentação

A documentação está dividida em três áreas.

## Planning

Define o produto, o escopo e o trabalho necessário.

- Visão
- Objetivos
- Fora de escopo
- Métricas
- Riscos
- Marcos
- Épicos
- Histórias de usuário
- Tarefas
- Questões em aberto

## Engineering

Define como o sistema será construído, validado e entregue.

- Arquitetura
- Estrutura de pastas
- Padrões de código
- Guia de contribuição
- Estratégia de testes
- CI/CD
- Estratégia de releases
- Dívida técnica

## ADR

Registra decisões arquiteturais importantes, incluindo contexto, alternativas e consequências.
