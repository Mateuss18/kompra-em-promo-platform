# ADR-0004 — PrimeVue com Tailwind CSS

## Status

Aceito

## Contexto

O painel precisa de tabelas, formulários, diálogos e componentes administrativos, mantendo liberdade visual.

## Opções consideradas

- Vuetify.
- PrimeVue.
- Naive UI.
- Componentes próprios.

## Decisão

Usar PrimeVue para componentes e Tailwind CSS para layout e utilitários.

## Consequências

- Desenvolvimento mais rápido.
- DataTable e componentes administrativos maduros.
- É necessário controlar consistência visual entre componentes e utilitários.
