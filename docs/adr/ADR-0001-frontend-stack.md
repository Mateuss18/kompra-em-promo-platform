# ADR-0001 — Stack do frontend

## Status

Aceito

## Contexto

O frontend precisa oferecer boa produtividade, tipagem, componentes maduros e flexibilidade visual.

## Opções consideradas

- Vue 3 com TypeScript e Vite.
- React ou Next.js.
- Vue com Quasar.

## Decisão

Usar Vue 3, TypeScript e Vite, com Pinia, Vue Router, Axios, VeeValidate, Zod e Lucide Icons.

## Consequências

- Stack conhecida e adequada a um painel administrativo.
- TypeScript reduz erros de integração.
- O frontend permanece separado do backend.
