# Architecture Decision Records

ADRs registram decisões técnicas relevantes.

## Formato

- Título.
- Status.
- Contexto.
- Opções consideradas.
- Decisão.
- Consequências.

## Status possíveis

- Proposto
- Aceito
- Substituído
- Rejeitado
- Obsoleto
