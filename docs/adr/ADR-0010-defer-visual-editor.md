# ADR-0010 — Adiar editor visual para depois do MVP

## Status

Aceito

## Contexto

Um editor no estilo Canva aumenta consideravelmente o escopo e não é necessário para validar o fluxo de afiliados.

## Opções consideradas

- Incluir Konva.js desde o início.
- Adiar o editor visual.

## Decisão

Entregar primeiro imagem simples com foto do produto e slogan. Implementar Konva.js como primeira grande evolução pós-MVP.

## Consequências

- MVP menor e mais rápido.
- A arquitetura dos templates deve prever evolução.
- O resultado visual inicial será limitado.
