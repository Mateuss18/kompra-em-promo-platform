# Plano de Implementação do MVP

## Etapa 1 — Frontend com mocks

- Setup.
- Layout.
- Login simulado.
- Rotas.
- Dashboard.
- Lista de promoções.
- Editor.
- Aprovação simulada.
- Persistência local.
- Histórico simulado.

## Etapa 2 — Backend base

- Fastify.
- Prisma.
- PostgreSQL.
- Autenticação própria.
- CRUD.
- Auditoria.
- Integração frontend/API.

## Etapa 3 — Ingestão

- Formulário de link.
- Bot privado.
- Detecção de loja.
- Jobs assíncronos.
- Tratamento de falhas.

## Etapa 4 — Produto e afiliado

- Coleta de título, imagem, preço e disponibilidade.
- Normalização de URL.
- Aplicação ou validação de tag de afiliado.
- Tela de revisão.

## Etapa 5 — Conteúdo

- Template de mensagem.
- Imagem simples com foto e slogan.
- Preview.
- Aprovação.

## Etapa 6 — Publicação

- Telegram oficial.
- Idempotência.
- Histórico.
- Reenvio.
- Cópia manual para WhatsApp.

## Etapa pós-MVP

Implementar o editor visual com Konva.js e templates avançados por loja.
