# Métricas de Sucesso

## Métricas do MVP frontend

- Todas as rotas principais acessíveis.
- Promoções mockadas carregadas por uma camada de serviço.
- Busca e filtros funcionando.
- Edição de promoção persistida localmente.
- Aprovação e publicação simuladas alterando o status.
- Estados de carregamento, vazio e erro presentes.
- Layout utilizável em desktop e mobile.

## Métricas do MVP completo

- Criar um rascunho a partir de um link válido das três lojas suportadas.
- Identificar corretamente a loja em pelo menos 95% dos links válidos testados.
- Gerar link de afiliado ou preservar corretamente a identificação existente.
- Reduzir o tempo médio de preparação de uma promoção para menos de dois minutos.
- Exigir aprovação antes de qualquer publicação.
- Registrar o resultado de toda tentativa de publicação.
- Evitar publicação duplicada por ação acidental.
- Permitir que a equipe localize uma promoção anterior rapidamente.

## Critério de validação

O MVP será considerado útil quando o fluxo completo, do recebimento do link à publicação no Telegram, puder ser realizado sem montar manualmente a mensagem e a imagem fora da plataforma.
