# Histórias de Usuário

## Autenticação e acesso

### US-001 — Login simulado

Como administrador, quero entrar com um login simulado para acessar e validar o frontend antes da implementação do backend.

### US-002 — Logout

Como administrador, quero encerrar a sessão simulada para testar o fluxo de acesso.

## Promoções

### US-003 — Listar promoções

Como administrador, quero visualizar as promoções para saber quais precisam de atenção.

### US-004 — Pesquisar e filtrar

Como administrador, quero pesquisar por título e filtrar por loja ou status para encontrar promoções rapidamente.

### US-005 — Visualizar detalhes

Como administrador, quero abrir uma promoção para conferir todos os dados coletados.

### US-006 — Editar promoção

Como administrador, quero corrigir título, preço, cupom e mensagem antes da aprovação.

### US-007 — Conferir link de afiliado

Como administrador, quero visualizar o link final para confirmar que a promoção poderá gerar comissão.

### US-008 — Visualizar imagem simples

Como administrador, quero conferir a imagem com a foto do produto e o slogan antes da publicação.

### US-009 — Aprovar promoção

Como administrador, quero aprovar um rascunho revisado para liberá-lo para publicação.

### US-010 — Rejeitar promoção

Como administrador, quero rejeitar uma promoção inadequada e registrar o motivo.

### US-011 — Simular publicação

Como administrador, quero simular a publicação no frontend para validar o fluxo sem Telegram real.

## Entrada de links

### US-012 — Enviar link pelo painel

Como administrador, quero colar um link no painel para criar um novo rascunho.

### US-013 — Enviar link pelo Telegram privado

Como administrador, quero enviar um link no grupo privado para que o sistema crie um rascunho automaticamente.

### US-014 — Detectar loja

Como administrador, quero que o sistema identifique automaticamente Shopee, Amazon ou Mercado Livre.

## Publicação

### US-015 — Publicar no Telegram

Como administrador, quero publicar uma promoção aprovada no canal oficial.

### US-016 — Copiar para WhatsApp

Como administrador, quero copiar a mensagem final para enviá-la manualmente ao WhatsApp.

### US-017 — Consultar histórico

Como administrador, quero consultar publicações anteriores e seus resultados.

## Evoluções

### US-018 — Editar template visual

Como administrador, quero montar artes mais elaboradas em um editor visual após a conclusão do MVP.

### US-019 — Trabalhar com outros papéis

Como responsável pelo sistema, quero futuramente permitir usuários `EDITOR` e `VIEWER`.
